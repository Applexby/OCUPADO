# OCUPADO

Página del cortometraje animado **OCUPADO** (2D, tinta y acuarela).

Sitio estático: `index.html` y la carpeta `assets/`. No necesita compilación; en Vercel basta con importar el repositorio.

## Narración

La historia se puede escuchar en la web, narrada con ElevenLabs (voz Kate - Serene Narrator Pro, Eleven v4).

- `audio/ocupado-historia.mp3` y `audio/ocupado-final.mp3`: las dos narraciones (el final va aparte para respetar el aviso de spoilers).
- `audio/guion/`: los textos con las etiquetas de emoción que se pegaron en ElevenLabs.
- Los tiempos de cada palabra (alineación forzada de ElevenLabs) están en `index.html` (`SYNC`) y hacen que el texto se resalte mientras suena. Si se regenera un audio, hay que volver a alinearlo.
